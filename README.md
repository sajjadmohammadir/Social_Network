## 1. مقدمه و هدف پروژه

در این پروژه، یک برنامه کامپیوتری ساخته‌ایم که یک شبکه اجتماعی را ذخیره و تحلیل می‌کند. شبکه اجتماعی یعنی مجموعه‌ای از آدم‌ها که بعضی‌هایشان با هم دوست هستند. مثلاً فرض کنید در یک کلاس درس ۳۰ نفر هستند. بعضی‌ها با هم رفیق هستند و بعضی‌ها نه. این برنامه می‌تواند بفهمد چه کسی با چه کسی دوست است، کوتاه‌ترین راه بین دو نفر چیست، و اطلاعات مفید دیگری را استخراج کند.

هدف اصلی این پروژه نشان دادن این است که چگونه می‌توان با استفاده از ساختمان داده‌های ساده مثل دیکشنری و مجموعه، یک شبکه اجتماعی کامل را ذخیره و پردازش کرد، بدون آنکه از کتابخانه‌های آماده پردازش گراف استفاده کنیم.

### قابلیت‌های اصلی برنامه:

- افزودن، ویرایش و حذف کاربران در شبکه
- ایجاد و حذف رابطه دوستی بین کاربران
- پیدا کردن کوتاه‌ترین مسیر بین دو کاربر
- پیشنهاد دوست بر اساس دوستان مشترک
- پیدا کردن گروه‌های مجزای دوستی در شبکه
- محاسبه آمار کلی شبکه
- محاسبه فاصله یک کاربر تا تمام کاربران دیگر
- نمایش بصری گراف شبکه در مرورگر

## 2. گراف چیست؟

گراف یک مفهوم ریاضی بسیار ساده است. گراف فقط از دو چیز تشکیل شده:

- **رأس یا گره (Vertex):** هر نقطه‌ای که یک چیز را نشان می‌دهد. در پروژه ما، هر کاربر شبکه اجتماعی یک رأس است.
- **یال (Edge):** خطی که دو رأس را به هم وصل می‌کند. در پروژه ما، اگر دو کاربر با هم دوست باشند، بینشان یک یال وجود دارد.

> **مثال ساده:** فرض کنید سه نفر داریم: امیر، حسن و علی. امیر با حسن دوست است و حسن با علی. پس گراف ما سه رأس و دو یال دارد:
>
> `امیر ---- حسن ---- علی`

در این پروژه، کاربران شبکه اجتماعی رأس‌های گراف هستند و دوستی‌ها یال‌های آن هستند. از آنجا که دوستی دوطرفه است (یعنی اگر امیر دوست حسن باشد، حسن هم دوست امیر است)، گراف ما بدون جهت یا **Undirected** نامیده می‌شود.

## 3. ساختمان داده‌های استفاده شده

برای ذخیره شبکه اجتماعی در حافظه کامپیوتر، از دو دیکشنری ساده پایتون استفاده کردیم. دیکشنری یک ساختمان داده است که جفت‌های کلید-مقدار را نگه می‌دارد و جستجو در آن بسیار سریع است.

### دیکشنری اول: کاربران (users)

این دیکشنری، شناسه عددی هر کاربر را به نام او نگه می‌دارد:

```python
users = {
    "1": "امیر",
    "2": "حسن",
    "3": "علی"
}
```

**مزیت:** اگر بخواهیم نام کاربری با شناسه ۲ را پیدا کنیم، فقط کافی است بنویسیم `users["2"]` و بلافاصله جواب «حسن» را می‌گیریم. این کار فقط O(1) زمان می‌برد.

### دیکشنری دوم: لیست مجاورت (adj)

این دیکشنری برای هر کاربر، مجموعه‌ای از شناسه دوستانش را نگه می‌دارد:

```python
adj = {
    "1": {"2", "3"},    # امیر با حسن و علی دوست است
    "2": {"1"},          # حسن با امیر دوست است
    "3": {"1"}           # علی با امیر دوست است
}
```

**مزیت مجموعه (Set):** بررسی اینکه آیا دو نفر دوست هستند فقط O(1) زمان می‌برد.

### چرا لیست مجاورت بهتر از ماتریس مجاورت است؟

| روش | فضا | مناسب برای |
|---|---|---|
| ماتریس مجاورت | O(V²) | گراف‌های متراکم |
| لیست مجاورت | O(V+E) | گراف‌های کم‌تراکم مثل شبکه اجتماعی |

در شبکه‌های اجتماعی معمولاً همه با همه دوست نیستند، پس لیست مجاورت فضای خیلی کمتری مصرف می‌کند.

## 4. ذخیره‌سازی اطلاعات با JSON

وقتی برنامه بسته می‌شود، اطلاعات حافظه از بین می‌روند. برای حل این مشکل، اطلاعات را در یک فایل JSON ذخیره می‌کنیم:

```json
{
    "users": {"1": "امیر", "2": "حسن"},
    "edges": [{"a": "1", "b": "2"}]
}
```

**تابع ذخیره (save):** دیکشنری‌ها را در فایل می‌نویسد. برای جلوگیری از تکرار، فقط دوستی‌هایی ذخیره می‌شوند که شناسه کاربر اول کوچک‌تر از دومی باشد.

**تابع بارگذاری (load):** فایل JSON را می‌خواند و دیکشنری‌ها را بازسازی می‌کند. اگر فایل نباشد، شبکه نمونه بارگذاری می‌شود.

## 5. الگوریتم ۱: لیست دوستان

ساده‌ترین الگوریتم پروژه. فقط کافی است به دیکشنری مجاورت نگاه کنیم:

```python
def friends(self, user_id):
    friend_ids = adj[user_id]
    return [users[f] for f in friend_ids]
```

**پیچیدگی زمانی:** O(k) که k تعداد دوستان کاربر است.

## 6. الگوریتم ۲: بررسی ارتباط

### ارتباط مستقیم

```python
def directly_connected(self, a, b):
    return b in adj[a]
```

**پیچیدگی:** O(1)

### ارتباط غیرمستقیم

گاهی دو نفر مستقیماً دوست نیستند ولی از طریق آدم‌های دیگر به هم وصل هستند. برای فهمیدن این موضوع، از الگوریتم BFS استفاده می‌کنیم.

## 7. الگوریتم ۳: کوتاه‌ترین مسیر (BFS)

BFS مخفف **Breadth-First Search** به معنی جستجوی اول عرض یا سطح به سطح است. این الگوریتم مثل این است که در یک مهمانی دنبال یک نفر خاص می‌گردید:

1. **مرحله اول:** تمام دوستانتان را نگاه می‌کنید.
2. **مرحله دوم:** تمام دوستانِ دوستانتان را نگاه می‌کنید.
3. **ادامه:** تا پیدا کنید.

اولین مسیری که BFS پیدا می‌کند، حتماً کوتاه‌ترین مسیر است.

### پیاده‌سازی با صف (Queue)

```python
queue = deque([start_user])
visited = {start_user}
parent = {}

while queue:
    current = queue.popleft()
    if current == target:
        return build_path()
    for friend in adj[current]:
        if friend not in visited:
            visited.add(friend)
            parent[friend] = current
            queue.append(friend)
```

**پیچیدگی زمانی:** O(V+E)

> **مثال:** شبکه‌ای با این دوستی‌ها: امیر-حسن، حسن-سارا، سارا-نیکا  
> کوتاه‌ترین مسیر از امیر تا نیکا: امیر ← حسن ← سارا ← نیکا (۳ گام)

---

## 8. الگوریتم ۴: پیشنهاد دوست

ایده: اگر کسی دوستِ دوستِ شماست ولی هنوز دوست مستقیم شما نیست، احتمالاً گزینه خوبی است.

### مراحل کار:

1. تمام دوستان مستقیم کاربر را پیدا می‌کنیم.
2. برای هر دوست، دوستانِ آن دوست را بررسی می‌کنیم.
3. کسانی که دوست مستقیم ما نیستند، کاندید هستند.
4. کاندیدها را بر اساس تعداد دوستان مشترک مرتب می‌کنیم.

```python
my_friends = adj[user_id]
candidates = {}

for friend in my_friends:
    for friend_of_friend in adj[friend]:
        if friend_of_friend != user_id:
            if friend_of_friend not in my_friends:
                candidates[friend_of_friend] += 1

sorted(candidates, key=candidates.get, reverse=True)
```

**پیچیدگی زمانی:** O(k×m)

## 9. الگوریتم ۵: پیدا کردن گروه‌ها (DFS)

DFS مخفف **Depth-First Search** به معنی جستجوی اول عمق است. به جای سطح به سطح، یک مسیر را تا آخر می‌رویم و بعد برمی‌گردیم.

### مراحل پیدا کردن گروه‌ها:

1. یک کاربر را انتخاب می‌کنیم که هنوز ندیده‌ایم.
2. با DFS تمام کاربران متصل به او را پیدا می‌کنیم (یک گروه).
3. اگر کاربر ندیده‌ای مانده، از او شروع می‌کنیم (گروه بعدی).

```python
for user in users:
    if user not in visited:
        group = []
        stack = [user]
        while stack:
            current = stack.pop()
            if current not in visited:
                visited.add(current)
                group.append(current)
                for neighbor in adj[current]:
                    if neighbor not in visited:
                        stack.append(neighbor)
        groups.append(group)
```

**پیچیدگی زمانی:** O(V+E)

## 10. الگوریتم ۶: بیشترین دوست

```python
max_count = 0
best_user = None
for user in users:
    count = len(adj[user])
    if count > max_count:
        max_count = count
        best_user = user
```

**پیچیدگی زمانی:** O(V)

## 12. الگوریتم ۸: آمار شبکه

| آمار | روش محاسبه | پیچیدگی |
|---|---|---|
| تعداد کل کاربران | اندازه دیکشنری کاربران | O(1) |

## 13. الگوریتم ۹: فاصله از تمام کاربران

از همان BFS استفاده می‌کنیم ولی تا آخر ادامه می‌دهیم:

```python
distances = {}
queue = deque([(start_user, 0)])
visited = {start_user}

while queue:
    current, dist = queue.popleft()
    distances[current] = dist
    for friend in adj[current]:
        if friend not in visited:
            visited.add(friend)
            queue.append((friend, dist + 1))
```

**پیچیدگی زمانی:** O(V+E)

## 14. بخش‌های اختیاری (بونس)

### ۱۴.۱ پیدا کردن فرد کلیدی (مرکزیت بینابینی)

این الگوریتم مهم‌ترین فرد شبکه را پیدا می‌کند. فرد کلیدی کسی است که بیشترین نقش را در اتصال آدم‌ها به هم دارد. اگر او حذف شود، شبکه از هم می‌پاشد.

**مثال:** فرض کنید دو گروه دوستی وجود دارد و فقط یک نفر (حسن) بین آن‌ها واسطه است. اگر حسن برود، دو گروه کاملاً جدا می‌شوند.

**روش:** الگوریتم برندیز — برای هر کاربر مبدأ، BFS اجرا می‌کنیم و می‌شماریم هر کاربر چند بار در مسیرهای کوتاه واسطه بوده است.

```python
centrality = {user: 0 for user in users}

for source in users:
    # BFS از مبدأ
    distances = {}
    sigma = {user: 0 for user in users}
    predecessors = {user: [] for user in users}
    sigma[source] = 1
    distances[source] = 0
    queue = deque([source])
    order = []

    while queue:
        current = queue.popleft()
        order.append(current)
        for neighbor in adj[current]:
            if neighbor not in distances:
                distances[neighbor] = distances[current] + 1
                queue.append(neighbor)
            if distances[neighbor] == distances[current] + 1:
                sigma[neighbor] += sigma[current]
                predecessors[neighbor].append(current)

    # تجمیع وابستگی
    dependency = {user: 0 for user in users}
    for w in reversed(order):
        for v in predecessors[w]:
            if sigma[w] > 0:
                dependency[v] += (sigma[v]/sigma[w]) * (1 + dependency[w])
        if w != source:
            centrality[w] += dependency[w]

key_person = max(centrality, key=centrality.get)
```

**پیچیدگی زمانی:** O(V × (V+E))

### ۱۴.۲ تشخیص جوامع یا اکیپ‌های دوستی

این الگوریتم درون یک گروه بزرگ متصل، زیرگروه‌هایی را پیدا می‌کند که اعضایشان بیشتر با هم دوست هستند تا با بقیه.

**مثال:** در یک کلاس ۳۰ نفره، شاید ۳ تا اکیپ ۱۰ نفره وجود داشته باشد.

**روش:** رویکرد حریصانه — هر کاربر را به جامعه‌ای منتقل می‌کنیم که بیشترین ارتباط را با آن دارد.

```python
communities = {user: i for i, user in enumerate(users)}
changed = True

while changed:
    changed = False
    for user in users:
        best_community = communities[user]
        best_gain = 0
        neighbor_communities = {communities[f] for f in adj[user]}

        for comm in neighbor_communities:
            if comm == communities[user]:
                continue
            edges_to_comm = sum(1 for f in adj[user] if communities[f] == comm)
            current_edges = sum(1 for f in adj[user] if communities[f] == communities[user])
            gain = edges_to_comm - current_edges
            if gain > best_gain:
                best_gain = gain
                best_community = comm

        if best_community != communities[user]:
            communities[user] = best_community
            changed = True
```

**پیچیدگی زمانی:** O(V × E)

### ۱۴.۳ بهینه‌سازی انتشار خبر

فرض کنید می‌خواهیم خبری را در شبکه پخش کنیم. قانون: هر کسی خبر را بشنود، فردا به تمام دوستانش می‌گوید. هر کاربر فقط یک بار می‌شنود.

**سوال:** اگر فقط K نفر را انتخاب کنیم، چه کسانی باعث می‌شوند خبر سریع‌تر و بیشتر پخش شود؟

**روش:** رویکرد حریصانه — در هر مرحله، کاربری را انتخاب می‌کنیم که بیشترین پوشش جدید را ایجاد کند.

```python
def optimal_spread(k):
    selected = []
    remaining = set(users)
    for _ in range(k):
        best_user = None
        best_reach = -1
        for candidate in remaining:
            test_set = set(selected) | {candidate}
            reached = simulate_spread(test_set)
            if len(reached) > best_reach:
                best_reach = len(reached)
                best_user = candidate
        selected.append(best_user)
        remaining.remove(best_user)
    return selected

def simulate_spread(seed_users):
    reached = set(seed_users)
    current_layer = set(seed_users)
    while current_layer:
        next_layer = set()
        for user in current_layer:
            for friend in adj[user]:
                if friend not in reached:
                    reached.add(friend)
                    next_layer.add(friend)
        current_layer = next_layer
    return reached
```

**پیچیدگی زمانی:** O(K × V × (V+E))

### راهنمای استفاده

- **نوار کناری:** لیست کاربران و دکمه‌های افزودن، ویرایش و حذف
- **تب مدیریت دوستی:** افزودن یا حذف رابطه دوستی بین دو کاربر
- **تب‌های دیگر:** هر تب یکی از الگوریتم‌های تحلیل شبکه را اجرا می‌کند
- **دکمه بارگذاری نمونه:** شبکه نمونه از صورت پروژه را بارگذاری می‌کند

### نکات مهم

- تمام اطلاعات به صورت خودکار در فایل `network.json` ذخیره می‌شوند.
- از هیچ پایگاه داده‌ای استفاده نشده و فقط فایل JSON به کار رفته است.
- از هیچ کتابخانه پردازش گرافی استفاده نشده و تمام الگوریتم‌ها از صفر پیاده‌سازی شده‌اند.
- Flask فقط برای نمایش رابط کاربری وب استفاده شده و نقشی در پردازش گراف ندارد.
- تمام الگوریتم‌ها با هدف حداقل کردن پیچیدگی زمانی انتخاب و پیاده‌سازی شده‌اند.

## خلاصه پیچیدگی الگوریتم‌ها

| الگوریتم | پیچیدگی زمانی | ساختمان داده |
|---|---|---|
| لیست دوستان | O(k) | دیکشنری + مجموعه |
| ارتباط مستقیم | O(1) | مجموعه |
| کوتاه‌ترین مسیر | O(V+E) | صف (BFS) |
| پیشنهاد دوست | O(k×m) | دیکشنری + مجموعه |
| گروه‌ها | O(V+E) | پشته (DFS) |
| بیشترین دوست | O(V) | پیمایش خطی |
| دوستان مشترک | O(min(k1,k2)) | اشتراک مجموعه |
| آمار شبکه | O(V+E) | ترکیب الگوریتم‌ها |
| فاصله‌ها | O(V+E) | صف (BFS) |
| فرد کلیدی | O(V×(V+E)) | الگوریتم برندیز |
| جوامع | O(V×E) | رویکرد حریصانه |
| انتشار خبر | O(K×V×(V+E)) | شبیه‌سازی حریصانه |
